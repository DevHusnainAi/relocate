### What changed in the redesign (per ZeroDOM audit)

- **admin** — `data-testid` renamed (`save-btn` → `save-button`), button label changed (`Delete` → `Remove`), user-row `id` anchor dropped in favour of text-based row targeting, search placeholder updated (`Search users` → `Search members`)
- **checkout** — submit button `id` renamed (`submit-v1` → `place-order`)
- **nav** — cart anchor class renamed (`cart-link` → `nav-link--cart`)
- **promo** — input class removed, now identified by `name='promo'`

No assertions were touched. All patches were applied exclusively via [`relocate.ts patch`](relocate.ts). Proof artefacts (before/after screenshots + receipt) are in [`relocate-proof/`](relocate-proof/).
